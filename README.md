# eext-component-box

智能器件盒管理器 — 基于嘉立创EDA专业版的智能器件盒硬件上位机插件

## 功能介绍

### 个人器件库

- **导入 LCSC 订单表格**：支持导入 `.xls` / `.xlsx` 格式的立创商城订单文件，自动解析商品编号（C 编号）和数量
- **批量查询器件信息**：通过 LCSC 编号批量查询器件名称、封装、描述、制造商等信息
- **器件搜索与筛选**：支持按编号、名称、描述、制造商关键字实时搜索
- **器件编辑与删除**：支持编辑器件属性（名称、封装、数量等），支持批量选择删除
- **一键放置器件**：在原理图或 PCB 编辑器中直接放置器件库中的元件，放置后自动扣减库存

### 器件盒管理
[硬件说明](Hardware/README.md)  
- **5x7 格栅映射**：软件界面模拟物理器件盒的 5 行 x 7 列布局，每个格位可映射一个器件
- **双击分配器件**：双击格位弹出器件选择器，从器件库中选取器件分配到对应位置
- **器件信息显示**：悬停格位可查看器件名称、编号和库存数量
- **实时同步**：在软件端模拟硬件 OLED 屏幕及五个按键，实时双向同步。
